# 친구들끼리 바둑이

친구들끼리 즐기는 가로형 로우바둑이 웹게임입니다.

## 바로 접속
https://ehdgus440-create.github.io/friends-badugi/

## 주요 기능
- 모바일 가로 화면 · 프리미엄 카지노 테이블
- AI 연습: 나 포함 5명
- 아침·점심·저녁 카드 교환과 베팅
- 삥·하프·풀, 카드 선택 표시 및 쇼다운
- 방 만들기 및 4자리 초대 코드 (별도 실시간 연결 검증 필요)

## 자동 배포
`main` 브랜치에 변경 사항을 커밋하면 `.github/workflows/deploy.yml`에 설정된 GitHub Actions가 GitHub Pages에 자동 배포합니다.

**GitHub에서 수정했다고 자동으로 변경되는 것이 아니라 GitHub에 커밋되어야 웹에 반영됩니다.**

## 온라인 플레이 제약
현재 온라인 방 기능은 외부 PeerJS 연결에 의존합니다. GitHub Pages는 정적 웹 호스팅이므로 실시간 게임 서버를 제공하지 않습니다. 서로 다른 휴대폰의 연결, 카드 비공개 및 동기화는 별도 검증과 개선이 필요합니다.
